Error & edge states

Every state a user can land in when the route lookup fails. Icons are drawn as stroke SVG — the shipped build currently uses emoji placeholders, which these replace.

NETWORK · Loading screen
You appear to be offline.
Retry is the right action — the user can fix this themselves by reconnecting.
NOT_FOUND · Loading screen
We couldn't find a route to "Line 9 Platform".
No Retry here — repeating the same query gives the same answer. Send them back to re-type instead.
INVALID_REQUEST · Loading screen
Something's off with this request.
A bad placeId is our bug, not theirs — don't blame the user, just give them a way forward.
SERVER_ERROR · Loading screen
Something went wrong on our end.
Transient by nature, so Retry earns its place — a second attempt often succeeds.
MAP UNAVAILABLE · Guidance screen
Map unavailable for this step 1F → B7
Shown when a node has no mapped coordinate or the image fails. The floor badge stays, and the written instruction below carries the guidance on its own.
LEAVE CONFIRM · Guidance screen
Leave this guide? Your progress won't be saved.
Only from step 2 onward. On step 1 the close button leaves straight away — nothing has been invested yet.
